# sistem-panen — Penghitung Hasil Panen & Diskon

Deskripsi singkat Program Python sederhana untuk menghitung total nilai hasil panen dan menambahkan fitur perhitungan diskon berdasarkan persentase diskon yang diberikan.

## Cara Menjalankan Program

- Pastikan Python 3 sudah terpasang di komputer.
- Buka terminal atau Command Prompt.
- Masuk ke folder project dengan perintah `cd sistem-panen`.
- Jalankan program dengan perintah `py panen.py`.
- Program akan menampilkan jumlah panen, harga per kg, dan total nilai panen.
- Pada fitur diskon, program juga menampilkan persentase diskon dan total nilai panen setelah diskon.

## Fitur Program

- Menghitung total nilai hasil panen.
- Menampilkan jumlah panen dalam kg.
- Menampilkan harga panen per kg.
- Menghitung diskon berdasarkan persentase.
- Menampilkan total nilai panen setelah diskon.

## Contoh Perhitungan

Jumlah panen: 100 kg  
Harga per kg: Rp5000  
Total nilai panen: Rp500000
